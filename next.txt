  How to run (simulated)

  - Fusion
      - Generate samples:
          - python examples/fusion/make_synthetic_shots.py --out data/samples/fusion_shots
      - Offline eval:
          - python tools/eval_fusion_offline.py data/samples/fusion_shots --state-dim 8 --rank 4 --curvature-alarm 0.5 --out reports/fusion_offline_metrics.csv
      - Lp sweep:
          - python tools/eval_lp_sweep.py data/samples/fusion_shots --state-dim 8 --rank 4 --curvature-alarm 0.5 --p-grid "1.0,1.25,1.5,1.75,2.0" --lambda 1.0 --out reports/fusion_lp_sweep.csv
  - Supercon
      - Generate dataset: python examples/supercon/make_synthetic_dataset.py --out data/samples/supercon
      - Evaluate: python tools/eval_supercon_offline.py data/samples/supercon --state-dim 8 --rank 4 --alarm 0.5 --out reports/supercon_offline_metrics.csv
  - Materials Project (with MP_API_KEY)
      - pip install -e .[materials]
      - Python:
          - from compitum.integrations.materials_project_audit import audit_the_manifold
          - df = audit_the_manifold(os.environ["MP_API_KEY"], {"elements":["La","Ni","O"], "nelements":3})
      - Notebook: notebooks/examples/Crystal_Router.py
