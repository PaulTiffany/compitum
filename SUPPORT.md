# Support

Thanks for using Compitum! Here’s how to get help.

## How to Get Help
- Questions, ideas, or bugs: open an issue on GitHub
- Security issues: email paulctiffany@gmail.com (see SECURITY.md)
- Usage examples: see `examples/` and README quickstart

## Before Filing an Issue
- Search existing issues and discussions
- Include steps to reproduce, expected vs. actual behavior, and environment info
- Add minimal logs or stack traces when relevant

## Scope
We support the Compitum codebase in this repo. Upstream projects (e.g., RouterBench) are best handled with their maintainers; we’ll help triage where possible.
