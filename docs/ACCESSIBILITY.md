# Accessibility

We aim to make Compitum accessible to a wide audience:

- Documentation
  - Plain‑language summaries at the top of technical pages.
  - High‑contrast theme and responsive layout.
  - Meaningful link text; avoid color as the only cue.

- Artifacts and reports
  - Machine‑readable JSON alongside HTML for screen readers and tooling.
  - Tables include captions and units; figures include alt text.

- Contributions
  - Prefer semantic headings and list structure.
  - Include textual descriptions for non‑textual content.

If you encounter accessibility issues, please open an issue or email the maintainers.
